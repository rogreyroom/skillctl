01 // CAPABILITIES
01 // AUTO-DETECT

Reads your project stack

Parses package.json, composer.json, pyproject.toml, Cargo.toml, and config globs like nuxt.config.* against index.yaml without touching SKILL.md.

02 // DUAL MANIFEST

Personal + Team in one repo

Commit shared --copy skills in .skillctl.json while keeping personal --link skills in .skillctl.local.json — auto-hidden via .git/info/exclude.

03 // RAYCAST BRIDGE

Project skills inside Raycast

Uses ~/.config/raycast/skills exclusively for Raycast so you can switch active projects or pin extras without duplicating skills in Cursor or VS Code.

04 // CAPTURE

Save unknown repo skills

During skillctl init, discovers unmanaged skills in .agents/, .claude/, and .cursor/ so you can import them into your library and choose whether they stay in the repo.

05 // WORKTREES & GROUPS

Built for daily speed

Bundle skills into @nuxt or @ui groups with skillctl group, auto-inherit local manifests in fresh git worktrees, and tab-complete in zsh, bash, or fish.

06 // HARDENED

Doctor & security checks

Validates Raycast kebab-case rules, detects copy drift via SHA-256 hash, cleans legacy ~/.cursor/skills duplicates, blocks path traversal, and strips untrusted symlinks.

Quickstart in four commands

02 // DEPLOYMENT
STEP 01
skillctl setup

Configure your dotfiles library path, enable Antigravity / Claude Code targets, and migrate existing skills.

STEP 02
skillctl global add

Pick your minimal always-on skills (e.g. find-skills, grill-me) linked globally.

STEP 03
skillctl init

Run inside any project to detect stack matches, capture local skills, and sync personal or team copies.

STEP 04
skillctl doctor --fix

Verify frontmatter, repair broken links, clean legacy duplicates, and update drifted team copies.

04 // NODE 20+

MACOS

Full support for VS Code, Cursor, Antigravity, T3 Code (Codex + Claude Code), and the Raycast bridge.

eval "$(skillctl completion zsh)"

LINUX

Native symlinks across ~/.agents/skills, ~/.gemini/config/skills, and ~/.claude/skills.

eval "$(skillctl completion bash)"

WINDOWS (WSL)

Works out of the box in the WSL Linux filesystem (~/projects). Use --copy on /mnt/c if Developer Mode is off.

skillctl setup --yes && skillctl global sync
